# Planetsudo
This project only contains the planet sudo engine.
In order to implement a new AI please checkout the planetsudo.ai repository.

## API documentation

Build and serve the Javadocs for the agent interfaces and their German wrappers,
`MothershipInterface`, and `TowerInterface` with Docker Compose:

```shell
docker compose up --build
```

The documentation is available at <http://localhost:8080>.
